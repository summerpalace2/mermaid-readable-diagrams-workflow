# 工作流概览

本项目把流程图生成拆成“语义、基线、测量、布局、视觉、验收”六个阶段。六层之间有明确的责任边界：

```text
Mermaid 语义
    ↓
Mermaid 原始布局基线
    ↓
文字测量与动态卡片
    ↓
Constraint IR：rank / port / lane / symmetry / avoid
    ↓
正交路由与确定性 SVG
    ↓
渲染前硬校验 + 全量 QA + 全景人工确认
```

Mermaid 决定“谁连接谁”，布局代码决定“怎样连接更容易读”。如果同一张图无法同时满足语义、几何安全和可读性，应拆图或调整 Mermaid 分区，不应继续叠加线路。

## 对称规则

对称分为三类：

- `strict`：整张图关于同一条轴镜像；卡片、折点、通道、入边和标签都必须通过几何验收；
- `partial`：只对某些兄弟分支或子图声明镜像；不能把局部对称说成全图对称；
- `none`：拓扑不适合镜像时不强行对称，但仍必须保证线路不交叉、不卡片、不贴线。

公共脊柱是例外，不是默认行为。任何共享线段都必须同时列入 `publicSpine` 和对应的 `edgePairs`，否则视为非法共享。

## 主题规则

主题只属于 `visualModel`。生成新一批图之前先确认使用随机主题还是固定主题；如果选择随机，只在批次开始时抽取一次并记录结果。主题变化不能改变卡片尺寸、线路坐标或 Mermaid 内容。

## 验收闭环

渲染器负责在导出前阻断结构性错误，QA 负责独立扫描全部输出文件，人工预览负责确认缩放后的视觉重心和教学可读性。三者缺一不可：`crossings=0` 只能说明没有检测到真实交叉，不能单独证明图片好看。
